# Agent resources

Reference skills and working notes used while building Repsel Web. The `.agents/` directory is read-only in the current environment, so these files live here instead of being installed in the agent's discovery folder.

- Taste Skill, `design-taste-frontend`: [source](https://github.com/Leonxlnx/taste-skill), MIT.
- Impeccable: [source](https://github.com/pbakaus/impeccable), Apache-2.0.
- Emil Kowalski's design engineering skills: [source](https://github.com/emilkowalski/skill), MIT.
- The UI motion notes follow Emil's public [Great Animations article](https://emilkowal.ski/ui/great-animations).

The complete downloaded skill directories and license files are kept alongside this file. These references guide implementation; they are not runtime dependencies.
